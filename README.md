Gosto principalmente de aprender na prática, entender como as coisas funcionam e construir projetos do zero.

Atualmente, estou desenvolvendo meu principal projeto pessoal:

### 🤖 EVAN OS

O **EVAN OS (Edivan Virtual Assistant Native)** é um projeto de inteligência artificial pessoal desenvolvido em Python.

A ideia é construir uma inteligência artificial que possa:

* 🧠 Ter memória própria
* 💬 Conversar naturalmente
* 📚 Aprender novas informações
* 🗃️ Armazenar e recuperar memórias
* 📖 Auxiliar nos estudos
* 💻 Ajudar com programação
* 📄 Trabalhar com documentos e PDFs
* 🤖 Evoluir futuramente para um robô físico

O objetivo final é transformar o EVAN em uma **presença artificial capaz de acompanhar seu criador durante anos**, começando como um sistema para PC e futuramente chegando a uma plataforma robótica física.
